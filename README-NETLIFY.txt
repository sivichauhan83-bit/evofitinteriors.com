EVOFIT INTERIORS - NETLIFY (STATIC) VERSION
===========================================

HOW TO PUT IT ONLINE (2 minutes)
1. Unzip this package. Open the unzipped folder: you must SEE index.html, config.js
   and the assets folder directly inside it.
2. Go to https://app.netlify.com/drop  and drag THAT folder (the one containing index.html)
   onto the page. Do not drag a folder that only contains another folder - that gives a 404.
3. Netlify gives you a link. Open it: the full site loads.

BEFORE YOU SHARE THE LINK - edit config.js (open with Notepad)
   Put your WhatsApp number, phone, email and social links. Empty = not shown.
   Save, then drag the folder onto Netlify again (or Deploys -> drag and drop) to update.

ENQUIRY FORM (Netlify Forms)
   The form works automatically after the first deploy.
   To receive e-mails: Netlify dashboard -> your site -> Forms -> Form notifications -> Add notification -> Email.
   Every enquiry is also listed under Forms -> enquiry. (Netlify's free plan has a monthly submission limit.)
   Note: forms only work on the Netlify link, not when you open index.html from your computer.

CUSTOM DOMAIN: Netlify dashboard -> Domain management -> Add a domain.

TO CHANGE TEXT OR PHOTOS: edit index.html (text) or replace files in assets/img (keep the same file names).
   Replace assets/img/cards/residential.webp with your own residential photo.

PRIVACY: privacy.html is starter text only - have it reviewed before relying on it.

THE WORDPRESS PLUGIN (evofit-package-v1.1.zip) is only for a WordPress site. Netlify cannot run it.
